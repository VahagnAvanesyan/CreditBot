# CreditBot 🤖💳

A Telegram bot powered by Machine Learning that predicts the probability of loan approval based on user-provided financial and personal information.

## 📖 Overview

CreditBot is an interactive Telegram bot that collects loan application data through a conversational interface and uses a trained Machine Learning model to estimate whether a loan is likely to be approved.

The bot provides:

* Loan approval prediction
* Approval probability score
* User-friendly conversation flow
* Summary of submitted information
* Instant results through Telegram

---

## 🚀 Features

* Interactive Telegram chat interface
* Machine Learning-based predictions
* Approval probability calculation
* Loan application analysis
* Simple and intuitive user experience

### Information Collected

* Age
* Annual Income
* Home Ownership Status
* Employment Length
* Loan Purpose
* Credit Grade
* Loan Amount
* Interest Rate
* Loan-to-Income Ratio
* Previous Default History
* Credit History Length

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/VahagnAvanesyan/CreditBot.git
```

### Navigate to the Project Folder

```bash
cd CreditBot
```

### Install Dependencies

```bash
pip install python-telegram-bot numpy
```

---

## ▶️ Running the Bot

Start the bot:

```bash
python bot.py
```

Then open Telegram and send:

```text
/start
```

The bot will guide you through the loan application process step by step.

## 🔒 Security

For security reasons, Telegram Bot Tokens should never be stored directly in public repositories.

Instead of:

```python
TOKEN = "YOUR_TOKEN"
```

use environment variables:

```python
import os

TOKEN = os.getenv("BOT_TOKEN")
```
